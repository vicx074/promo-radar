# Promo Radar

Bot de curadoria de promoções para grupos próprios no WhatsApp. Backend em **Python/FastAPI**, banco local **SQLite**, integração isolada com **Evolution API v2**.

Este repositório está iniciando. A implementação inicial fica na branch `feat/backend-foundation` e será incorporada por pull request após revisão.

> Integração Baileys não oficial: risco de desconexão e restrições do WhatsApp. Nenhuma mensagem deve ser enviada sem aprovação explícita de um administrador.
